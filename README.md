# 우리 학교 탐정단: AI 추론 수사대

초등학교 4~6학년이 학교에서 일어난 가상의 사건을 조사하며 **AI가 정보를 정리하고 가설을 비교·검증하는 과정**을 체험하는 추리 게임입니다.

- 사건 5개 (난이도 하 1 · 중 2 · 상 2), 사건당 약 5분
- 3D 현장 조사 (끌어서 시점 이동, 확대·축소), 단서 수집, 탐정 수첩
- AI 조수 **부향이**(백제금동대향로 모양 로봇)의 단서 설명, AI에게 질문하기, 단계별 AI 종합 분석
- 최종 사건 보고서와 항목별 자동 평가
- 인터넷·외부 API 없이 오프라인으로 실행, 개인정보 수집 없음

## 실행 방법

- **가장 간단한 방법:** `학교 탐정단_한파일.html` 하나만 내려받아 Microsoft Edge나 Chrome으로 엽니다.
- **폴더 버전:** `game` 폴더를 통째로 내려받아 `game/학교 탐정단.html`을 엽니다.

## 인물 그림 바꾸기

`game/assets/characters/`에 정해진 이름의 PNG를 넣으면 기본 3D 인물 대신 그 그림이 나옵니다. 파일 이름은 `game/그림_넣기_안내.md`를 참고하세요.
그림을 바꾼 뒤 `game/도구/한파일_만들기.bat`을 실행하면 한 파일 버전이 다시 만들어집니다.
